## Problem

The pharmacy store needed to scale as a real e-commerce surface—catalog, checkout, and operations—not a brochure.

## Approach

I built and extended the store across Node.js, SQL, and React. The storefront and operations UI talked to one API; SQL held catalog and orders so those two views could not drift. Backend work focused on the catalog and checkout read path.

Full write-up: [Visit Health pharmacy](/writing/visit-health-pharmacy).

## Outcome

Features that shipped with this work contributed to a 50% boost in user engagement. Backend optimizations cut server response time by 20%.

## Tech

Node.js, SQL, and React.
